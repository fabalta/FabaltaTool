# Fabalta Tool

> Nem hivatalos Roblox segédeszköz. Executor szükséges.
> **Zárt forráskód – a script nem módosítható és nem terjeszthető.**

---

## 📖 Leírás

A **Fabalta Tool** egy könnyű, magyar nyelvű Roblox segédeszköz, amely számos hasznos funkciót kínál egy letisztult, drag & drop felületen.

A script **kulcsvédett**, és a kulcs **nem nyilvános** – kizárólag a fejlesztő adja ki jogosult felhasználóknak. A kulcs a fájlon belül van tárolva, de **senkivel nem osztható meg**.

---

- ❌ A script **nem módosítható**.

## ✨ Funkciók

| Kategória | Funkciók |
|-----------|----------|
| **Mozgás** | WalkSpeed, JumpPower, Végtelen Ugrás, Noclip, Fly, TP Tool |
| **Harc** | Aimbot, SilentAim, Godmode, AimSmooth |
| **Látvány** | FOV, Fullbright, ESP |
| **Eszközök** | Anti-AFK, Rejoin, Reset Karakter |
| **Animációk** | Bundle ID, egyedi Idle / Walk / Run / Jump ID |
| **Beállítások** | ToggleKey, konfiguráció mentése |

---

## 🚀 Használat

1. Szerezd meg a **kulcsot** a fejlesztőtől.
2. Nyisd meg a scriptet egy Roblox executorban.
3. Futtasd, majd add meg a kulcsot a felugró ablakban.
4. Kész – a menü megnyílik.

> A kulcs nélkül a script **nem indítható el**.

---

## 🎮 Vezérlés

| Bemenet | Funkció |
|---------|---------|
| `F12` | Menü megnyitása / bezárása |
| `X` | Script bezárása |
| `Ctrl + Bal klikk` | Teleportálás a kurzor helyére (TP Tool) |
| `Jobb klikk` | Aimbot aktiválása (tartás) |
| `Space` | Fly – felfelé |
| `LeftShift` | Fly – lefelé |

## ⚙️ Konfiguráció

A beállítások automatikusan mentődnek a `FabaltaTool_Max.json` fájlba, ha az executor támogatja a `readfile` és `writefile` függvényeket.
